# 役割と触る領域ごとに読むファイル

タスクに着手する前に、次の表の該当する行のファイルを全文読む。つまみ食いや要約読みをしない。表の行は足し算であり、「どの役も」の行に、触る領域の行を足して読む。触らない領域の行は読まない。読む量が多いと、サブエージェントは作業の途中でコンテキストを使い切るためである。

`.claude/規約/` はこのリポジトリの規約であり、`~/.claude/規約/` は全プロジェクト共通の規約である。`~/.claude` が無い PC では、先に `~/.claude` のリポジトリを clone する。

読み終えたら確認を返さず、そのままタスク本体に着手して完遂する。

| 役割・触る領域 | 読むファイル |
|---|---|
| どの役も | `~/.claude/規約/文章と語.md`。名前か文章を書く役は、あわせて `~/.claude/shared-knowledge/deprecated_words.csv` |
| コードを書く・検査する(C#) | `.claude/規約/コード/coding_rule.md`、`.claude/規約/コード/csharp_coding_rules.md`、`.claude/規約/コード/判別共用体の失敗パターン.md`、`~/.claude/規約/コード/設計.md`、`~/.claude/規約/コード/分割とコメント.md`、`~/.claude/規約/命名.md` |
| テストを書く・直す | `~/.claude/規約/テスト方法の選定.md` |
| 文書だけ書く | `~/.claude/skills/doc-writing/SKILL.md`、`.claude/規約/リポジトリの地図.md`(文書配置)、`README.md`(生存型文書の索引) |
| 検収・レビューをする | 検収する対象の行に加えて `~/.claude/規約/レビュー.md` |
| 親のセッション(将軍) | `.claude/規約/将軍.md` |
