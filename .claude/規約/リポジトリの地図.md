# リポジトリの地図

このファイルは、ONE.O.NET のリポジトリの入口(ツールの入口・文書置き場・旧リポジトリと試作の場所・まだ無いもの)を示す。ビルド・ツール・文書の配置に触る役が読む。

## ツールの入口

- ツールの入口は、リポジトリのルートの `tool.ps1` の1つである。番号・日本語名・日本語説明の一覧が対話表示され、番号入力で選んで実行できる。`-List` で一覧のみ出力し、`-Run <番号>` で直接実行する。
- 新しいツールを作ったときは、`tool.ps1` 冒頭の `$作業一覧` へ追記する。登録するまでがツールの作成である。
- 実行場所はどこでもよい。`tool.ps1` が自分の位置からリポジトリのルートを解決する。
- 今はツールが無い。`-List` は、ツールが登録されていないことを表示する。

## 文書置き場

- 生存型文書とは、現在の実装と一致している義務を負う文書のことである。置き場は `_doc/設計/` であり、索引は `README.md` の「文書一覧(生存型)」の1箇所である。登録なき文書作成を禁止する。索引への登録までが作成である。
- ログ型文書とは、書いた時点の記録であり、追記だけを行う文書のことである。調査などのログ型文書は `_doc/調査/` に置く。過去の記述を現在に合わせて直さない。
- 会話の逐語の開発スレッドは、リポジトリに作らない(`.claude/規約/将軍.md` の「引き継ぎ」)。

## 旧リポジトリと試作の場所

OneOnet の現行版(Python + TypeScript の Web UI 版)は、旧版(非公開のリポジトリ RefucteringVoiroStudio)にある。ネイティブ版の試作と、試作を決めた調査は、次の場所にある。

- 試作: 旧リポジトリの `prototypes/OneOnet.Native`
- 調査と試作の記録: 旧リポジトリの `_doc/企画設計実装解説/50_仕様検討・提案/Draft/` の `試作_2026-10-24_WinUI3と音声接続.md`・`調査_2026-10-24_CPU推論の音声認識とかな出力.md`・`調査_2026-10-24_SengenUI画面の静的と動的の割合.md`

## まだ無いもの

- ソリューション(`OneONet.sln`)とプロジェクト。コードは書き始めていない。
- .NET SDK の固定(`global.json`)。`csharp_coding_rules.md` 第1条のビルドは、SDK の固定が入るまで実行できない。
- 層と依存の向き。決めてから書き出す(`アーキテクチャ先行` スキル)。

## 命名

プログラムに影響する名前(名前空間・プロジェクト・アセンブリ・ソリューション)は、C# の推奨に従い PascalCase とし、`OneONet` で始める(例: 名前空間 `OneONet`、ソリューション `OneONet.sln`)。リポジトリのフォルダ名は `ONE.O.NET` である。
