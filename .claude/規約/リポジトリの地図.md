# リポジトリの地図

このファイルは、ONE.O.NET のリポジトリの入口(ツールの入口・文書置き場・旧版と試作の扱い・.NET SDK・SengenWinUI3 のサブモジュール・まだ無いもの)を示す。ビルド・ツール・文書の配置に触る役が読む。

## ツールの入口

- ツールの入口は、リポジトリのルートの `tool.ps1` の1つである。番号・日本語名・日本語説明の一覧が対話表示され、番号入力で選んで実行できる。`-List` で一覧のみ出力し、`-Run <番号>` で直接実行する。
- 新しいツールを作ったときは、`tool.ps1` 冒頭の `$作業一覧` へ追記する。登録するまでがツールの作成である。
- 実行場所はどこでもよい。`tool.ps1` が自分の位置からリポジトリのルートを解決する。
- 登録してあるツールは「ビルド」(ソリューション `OneONet.sln` のビルド)である。

## 文書置き場

- 生存型文書とは、現在の実装と一致している義務を負う文書のことである。置き場は `_doc/設計/` であり、索引は `README.md` の「文書一覧(生存型)」の1箇所である。登録なき文書作成を禁止する。索引への登録までが作成である。
- ログ型文書とは、書いた時点の記録であり、追記だけを行う文書のことである。調査などのログ型文書は `_doc/調査/` に置く。過去の記述を現在に合わせて直さない。
- 会話の逐語の開発スレッドは、リポジトリに作らない(`.claude/規約/将軍.md` の「引き継ぎ」)。

## 旧版と試作の扱い

OneOnet の現行版(Python + TypeScript の Web UI 版)は、旧版(非公開のリポジトリ RefucteringVoiroStudio)である。ネイティブ版の試作と、試作を決めた調査は、旧版の中にあり、このリポジトリからは辿れない。書き手は、旧版から受け継ぐ判断を、旧版の文書を指す形で書かず、規約と設計の文書の中に理由ごと書く。

## .NET SDK

- ビルドには、`global.json` で固定した .NET SDK を導入する。今は .NET 11 RC2(`11.0.100-rc.2.26504.105`)に固定してある。.NET 11 の正式版が出たら、正式版の SDK へ上げる。

## SengenWinUI3 のサブモジュール

- 画面の部品のライブラリ SengenWinUI3(https://github.com/megaDenryu/SengenWinUI3)は、git のサブモジュールとして `submodules/SengenWinUI3` に置く。`OneONet.UI` は `submodules/SengenWinUI3/src/SengenWinUI3/SengenWinUI3.csproj` を `ProjectReference` で参照する。
- クローンするときは `git clone --recurse-submodules https://github.com/megaDenryu/ONE.O.NET.git` とする。`--recurse-submodules` を付けずにクローンしたときと、サブモジュールの指すコミットが変わった変更を取り込んだときは、リポジトリのルートで `git submodule update --init` を実行する。
- SengenWinUI3 の最新へ進めるときは、リポジトリのルートで `git submodule update --remote submodules/SengenWinUI3` を実行し、`submodules/SengenWinUI3` の変更を ONE.O.NET でコミットする。
- SengenWinUI3 に部品を足すときは、`submodules/SengenWinUI3` の中で編集し、SengenWinUI3 のリポジトリとしてコミットして push してから、ONE.O.NET でサブモジュールの指すコミットの変更をコミットする。SengenWinUI3 を push する前に ONE.O.NET を push すると、他の人のクローンでサブモジュールのコミットが見つからなくなる。

## まだ無いもの

- 機能のコード。ソリューション(`OneONet.sln`)と層ごとのプロジェクト(`src/` の下)の骨組みだけがある。層と参照の向きは `_doc/設計/アーキテクチャ.md` にある。

## 命名

プログラムに影響する名前(名前空間・プロジェクト・アセンブリ・ソリューション)は、C# の推奨に従い PascalCase とし、`OneONet` で始める(例: 名前空間 `OneONet`、ソリューション `OneONet.sln`)。リポジトリのフォルダ名は `ONE.O.NET` である。
