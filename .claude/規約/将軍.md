# 親のセッション(将軍)の規約

将軍とは、リポジトリで作業を指揮する親のセッションのことである。このファイルは、将軍が作業を指揮する前に読むものと、引き継ぎの運用を定める。

## 将軍が読むもの

将軍は、作業を指揮する前に次を読む。短い質問に答えるだけのセッションは読まなくてよい。

- `.claude/規約/リポジトリの地図.md`
- `~/.claude/規約/` の `作業の進め方.md`・`オーナーとの対話.md`・`思考を伝えるための文章・表示設計方針.md`・`文章と語.md`・`レビュー.md`
- `~/.claude/shared-knowledge/deprecated_words.csv`(名前か文章を書く前に読む。このリポジトリに固有の非推奨語の一覧は無い)

将軍が自分でコードかテストを書くか、検収するときは、触るものに当たる次のファイルも読む。

- コード(C#): `.claude/規約/コード/coding_rule.md`・`.claude/規約/コード/csharp_coding_rules.md`・`.claude/規約/コード/判別共用体の失敗パターン.md`、`~/.claude/規約/コード/` の下(設計・分割とコメント)、`~/.claude/規約/命名.md`
- テスト: `~/.claude/規約/テスト方法の選定.md`

サブエージェントを起動するときは、定義を持つ型ならその定義が読むものを決めている。定義を持たない型へ頼むときは、読むファイルを命令に書く。役割と触る領域ごとに読むファイルの表は `.claude/commands/rule.md` にあり、命令にはこの表の該当行を写してよい。

## 引き継ぎ

将軍は、セッションを閉じるとき・再起動するとき・作業を区切って止めるときに、cost-meter のスキル `handoff` で引き継ぎを書く。引き継ぎとは、続きのセッションが会話を読まずに作業を再開できるように、今の状態と次にすることを書き残したもののことである。将軍は、引き継ぎを書く前に走っているサブエージェントを区切りで止め、作りかけをコミットさせる。将軍は、オーナーの決定と自分の判断を、決まった時点で規約・設計の文書・issue へ書き、引き継ぎにはそのパスだけを書く。

将軍は、会話の逐語の開発スレッドをリポジトリに作らない。続きのセッションが逐語を読むとコンテキストを大きく使うためである。逐語は Stop フック(`~/.claude/hooks/thread_mirror.py`)が毎ターン `~/.claude/thread-mirrors/<プロジェクトの正規化名>/` へ自動で書き出すので、オーナーの前の発言を確かめるときは、そのファイルを読まずに検索する。

コミットは `~/.claude/規約/作業の進め方.md` の節「コミットの粒度」に従う。
